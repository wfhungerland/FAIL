# cepr-fail

CEPR column "Let Europe fail better: Free what business failures release, faster", a spin-off of the FAIL project ("The Varieties of Failure"), intended for the CEPR series Europe 2050.

- `column.md`: column text, references and author bio (source for the Word file)
- `column.docx`: submission file, generated by `build_docx.py`
- `teaser.md`: teaser for the submission
- `pruefung.md`: fact-check log (German)

Related: the chapter "Scheitern und Neustart" in the Makrowolf, repository [hungerland-macro/macro](https://github.com/hungerland-macro/macro), uses official series on insolvencies and business births.
